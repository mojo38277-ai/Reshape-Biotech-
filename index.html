      How to Use

      • Test Panel: Enter results you already have. Click "Identify Bacteria" for ranked matches.
      • Why this match?: Expand each result to see how it was scored.
      • Next Tests: Get smart suggestions to separate close matches.
      • Export/History: Save or download results for your lab notes.
      • Tree Mode: Use the dichotomous tree if you prefer step-by-step.

      Quick Tips

      • More tests = higher confidence
      • Key tests (Gram, catalase, oxidase, coagulase) carry more weight
      • Leave fields as "Not tested" if unknown
      • Watch for conflicts in the breakdown
